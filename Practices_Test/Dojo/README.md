## 🎯 Quy Chuẩn Định Dạng Mỗi Câu Hỏi

Mỗi câu hỏi trong các file .md được cấu trúc chặt chẽ gồm:
1. **Tiêu đề câu hỏi & Phân loại:** Số thứ tự, loại câu (Single Choice / Multiple Choice) và Domain kiến thức AWS.
2. **Đề bài (Question):** Nội dung tình huống đề thi kèm mã nguồn và sơ đồ (nếu có).
3. **Các lựa chọn (Choices):** Dạng danh sách kiểm tra (- [x] cho phương án đúng, - [ ] cho phương án sai).
4. **Đáp án đúng (Correct Answer):** Blockquote nổi bật chỉ rõ ký tự đáp án đúng và nội dung tóm tắt.
5. **Giải thích chi tiết (Explanation):**
   - **Mục 1: Vì sao đáp án đúng? (Correct Answer Rationale):** Tổng quan kiến thức, sơ đồ minh họa kiến trúc AWS, lý do chọn phương án này.
   - **Mục 2: Vì sao các phương án khác sai? (Incorrect Options Rationale):** Phân tích từng phương án còn lại tại sao không phù hợp với yêu cầu bài toán.
   - **Mục 3: Tài liệu tham khảo (References & Cheat Sheets):** Liên kết trực tiếp đến AWS Documentation và Tutorials Dojo Cheat Sheet liên quan.
